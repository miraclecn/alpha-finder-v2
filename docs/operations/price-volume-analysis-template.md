# 个股量价分析模板

本模板只依据《量价分析：量价分析创始人威科夫的盘口解读方法》前述提炼内容编写，用于日常个股复盘与状态识别。

## 使用边界

- 只看 `价格` 与 `成交量`
- 核心判断是：`成交量是在确认价格，还是在否定价格`
- 成交量必须做 `相对比较`，不看孤立绝对值
- 单根 K 线只作 `预警`，不单独下结论
- 支撑位和压力位是 `区域`，不是精确点位
- 突破必须看 `成交量确认`
- 横盘越久，后续突破越值得重视
- 趋势不是靠趋势线预测，而是从 `吸筹 / 派发 / 横盘突破 / 量价确认` 中识别
- 不额外引入均线、MACD、RSI、估值、财务指标等书外口径

## 分析模板

```text
股票名称：
分析周期：
分析日期：

一、趋势背景
1. 当前大方向：上涨 / 下跌 / 横盘
2. 当前所处位置：低位 / 高位 / 区间内部 / 区间突破后 / 区间跌破后
3. 当前所处阶段初判：吸筹 / 拉升 / 派发 / 下跌 / 暂不明确

二、支撑位与压力位
1. 主要支撑区域：
2. 主要压力区域：
3. 支撑/压力依据：
   - 过去大量买卖发生的区域
   - 横盘区间
   - 价量密集区域（如有 VAP 可辅助观察）
4. 当前价格与支撑/压力的关系：
   - 接近支撑
   - 接近压力
   - 位于区间中部
   - 刚突破压力区域
   - 刚跌破支撑区域
5. 对支撑/压力的判断：
   - 该区域是否经历了较长时间横盘
   - 价格突破后是否又回到区间内部
   - 突破是否有成交量确认

三、量价关系
1. 当前价格表现：
   - 大幅上涨 / 小幅上涨 / 大幅下跌 / 小幅下跌 / 横盘
2. 当前成交量相对过去的表现：
   - 放量 / 缩量 / 常态
3. 成交量是否确认价格：
   - 确认 / 否定 / 异常
4. 对应量价含义：
   - 大幅上涨 + 放量：上涨较真实，买方有力量
   - 小幅上涨 + 缩量：正常的小波动，力量有限
   - 大幅上涨 + 缩量：异常，可能是假突破或诱多
   - 小幅上涨 + 放量：异常，可能有卖压吸收上涨
   - 大幅下跌 + 放量：下跌较真实，卖方强
   - 小幅下跌 + 缩量：正常弱波动
   - 大幅下跌 + 缩量：异常，跌势可能不可靠
   - 小幅下跌 + 放量：异常，可能有买盘吸收卖压

四、K 线观察
1. 实体大小：
   - 大实体 / 小实体
2. 上影线情况：
   - 是否明显偏长
   - 是否体现上方卖压
3. 下影线情况：
   - 是否明显偏长
   - 是否体现下方买盘承接
4. 关键 K 线：
   - 是否出现锤头线
   - 是否出现射击之星
5. K 线含义说明：
   - 锤头线 + 高成交量：可能说明卖盘被吸收
   - 射击之星 + 高成交量：可能说明高位卖压较强
6. 注意：
   - 单根 K 线不是交易信号
   - 必须结合成交量、位置、趋势、支撑阻力和后续确认

五、阶段识别
1. 吸筹阶段检查：
   - 是否经历下跌或坏消息冲击
   - 是否出现高成交量
   - 价格是否不再有效下跌
   - 是否出现长下影线、锤头线、低实体
   - 是否出现卖盘被吸收后的横盘震荡

2. 拉升阶段检查：
   - 是否突破横盘区间
   - 阳线实体是否扩大
   - 成交量是否配合放大
   - 回踩时成交量是否缩小
   - 上升过程中量价关系是否健康

3. 派发阶段检查：
   - 是否处于上涨后高位
   - 是否高位放量但价格涨不动
   - 是否出现长上影线、射击之星
   - 是否上涨越来越吃力
   - 是否成交量很大但实体变小
   - 是否进入高位震荡

4. 下跌阶段检查：
   - 是否跌破震荡区间
   - 阴线实体是否扩大
   - 成交量是否确认下跌
   - 反弹是否无量
   - 反弹时是否遇到大量卖压

六、关键反转信号
1. 放量止跌：
   - 是否快速下跌
   - 是否成交量明显放大
   - 是否出现长下影线、低实体、锤头线
   - 是否说明大量卖盘被买方吸收
   - 后续是否进入测试、横盘、再确认

2. 放量止涨：
   - 是否持续上涨后出现高成交量
   - 是否上涨幅度开始变小
   - 是否出现长上影线、射击之星、低实体
   - 是否说明大量买盘被卖方消化
   - 是否提示顶部派发风险上升

七、突破与回踩
1. 当前是否处于横盘区间突破阶段：
2. 突破是否有明显成交量确认：
3. 突破前横盘是否足够长：
4. 回踩支撑时成交量是否缩小：
5. 突破后是否重新跌回区间内部：

八、多周期确认
1. 高一级周期方向：
2. 当前周期信号是否与高一级周期一致：
3. 若不一致，是否属于逆大周期波动：

九、结论
1. 当前更接近的阶段：
   - 吸筹 / 拉升 / 派发 / 下跌 / 暂不明确
2. 当前上涨质量判断：
   - 健康上涨 / 上涨开始弱势 / 暂不适用
3. 结论依据：
   - 位置
   - 量价关系
   - K 线表现
   - 支撑位/压力位
   - 横盘/突破/回踩情况
4. 后续需要观察的确认信号：
   - 是否继续放量突破
   - 是否缩量回踩
   - 是否高位放量滞涨
   - 是否低位放量止跌
```

## 结论表述模板

```text
该股当前更接近【吸筹 / 拉升 / 派发 / 下跌】阶段。

依据是：
1. 当前价格处于【低位 / 高位 / 横盘区 / 突破区】；
2. 成交量对当前价格表现是【确认 / 否定 / 异常】；
3. K 线表现出【上方卖压 / 下方承接 / 实体缩小 / 长上影 / 长下影】；
4. 当前正处于【支撑区域 / 压力区域 / 区间突破 / 区间跌破】附近；
5. 后续仍需观察【测试 / 横盘 / 突破确认 / 缩量回踩】来完成判断。
```

## 复盘提醒

- 先看位置，再看量价，再看 K 线，最后看确认
- 低位放量与高位放量含义不同
- 真突破要有成交量确认
- 放量但价格走不动，要重点警惕
- 任何结论都要结合后续测试、横盘和突破结果
