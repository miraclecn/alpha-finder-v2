# up5in10 动态接回组合验证

## 口径

- 主规则仍为 `top10 + 120日位置10%-35% + 15%单仓 + 最多10仓 + 6%硬止损 + 15%启动/3%回撤动态止盈`。
- 接回仓位统一固定为 `5%`。
- 主规则新票优先级高于接回票。
- 接回只研究 A 系列：`A / A1 / A2 / A3 / A4`。
- `2026` 为截至当前数据的部分年份样本。

规则定义：

- `A`：原交易毛收益 `>=20%`，且次日开盘 `<=` 动态止盈卖出价。
- `A1`：`A + 卖出日成交量 < 前5日均量的1.5倍`。
- `A2`：`A1 + 原始持仓 >10天`。
- `A3`：`A1 + 原始涨幅处于25%-35%`。
- `A4`：`A1 + 次日开盘较卖出价折价至少2%`。

## 当前判断

这轮组合验证有三个核心结论：

1. 事件级上看起来更“干净”的 `A1/A2`，放到组合层后，并没有自然转化成更高组合收益。
2. 全样本连续资金曲线里，表现最好的是 `A4`，不是 `A1/A2`。
3. 但如果按 `2020 / 2021 / 2022-2025 / 2026截至当前` 分段看，`A4` 的优势并不稳定，仍然不能直接并入主规则。

分段判断：

- `2020`：`A / A1 / A4` 都优于基线，`A2` 因无信号而退化为基线。
- `2021`：大体中性，`A2 / A3` 反而略差。
- `2022-2025`：`A3` 最强，但只有 `7` 笔接回，更像高过拟合风险版本；`A4` 略优于基线且没有额外回撤；`A1 / A2` 胜率更高，但总收益没有超过基线。
- `2026`：所有接回版本当前都拖累表现。

## 组合层结论

这轮验证对上一轮事件级判断做了纠偏。

事件级里最漂亮的是 `A1/A2`，但组合级结果显示：

- `A1/A2` 更像“提高接回交易质量”，不等于“提高组合收益”
- `A4` 更像当前最接近组合可用的版本
- `A3` 收益最好，但样本太少，不适合直接上主规则

所以当前更合理的排序是：

1. `A4` 作为下一轮观察候选
2. `A1/A2` 作为高质量但偏稀疏的辅助版本
3. `A3` 暂时只保留为过拟合警报样本，不直接升级
4. 所有版本都还不能直接并入主规则
