# 2021-2026 top10 动态止盈组合回测

## 这版口径

本次按新的实盘口径重跑：

- 最多同时持有 `10` 只股票。
- 每只新仓目标约为当前总资产的 `10%`，现金不足则跳过。
- 信号日收盘后选股，下一交易日开盘买入。
- 买入当天不卖出，遵守 A 股 `T+1`。
- 硬止损为 `8%`：买入后第一个可卖日起，如果日内最低价跌到买入价下方 `8%`，按 `-8%` 卖出。
- 不设固定止盈。
- 不设最大持仓天数。
- 动态止盈采用移动止盈：先等股票从买入价上涨到启动盈利阈值，然后用已形成的高点作为跟踪高点；后续如果日内最低价跌破 `高点 * (1 - 回撤阈值)`，则卖出。
- 为避免日内高低顺序不可知，移动止盈只使用“此前已经形成的高点”，不假设同一天先创新高再回落卖出。
- 连续账本：`2021-01-04` 到 `2026-04-28` 不在年末强制平仓，持仓可以跨年；只在数据最后一天做会计强制平仓。
- 成本：买入 `12bp`，卖出 `12bp`。

本地数据覆盖：top10 信号从 `2021-01-04` 到 `2026-03-10`，交易日线到 `2026-04-28`。

## 参数说明

报告里的“启动8% / 回撤3%”意思是：

股票买入后，只有当最高价曾经达到 `+8%`，动态止盈才启动。启动后，如果之后从已形成高点回撤 `3%`，就卖出。

例如买入价 `10元`，后来最高到 `10.80元`，动态止盈启动。若之后跌到 `10.80 * 0.97 = 10.476元`，触发移动止盈。

## 关键判断

原始 top10 仍然不能直接用。虽然动态止盈让它从固定止盈止损的负收益变成正收益，但最大回撤超过 `50%`，说明它靠少数大趋势票拉回来，过程风险过高。

`120日位置10%-35%` 是这版规则下最值得继续研究的范围。它不是最低位，而是已经从低位反弹一段，但仍处在相对低位。这个范围的“启动8% / 回撤3%”参数，`2021-2026` 每个日历年都是正收益，最大回撤 `-18.5%`，持仓占用只有 `21.8%`，说明还有容量不足的问题，但风险形态比原始 top10 好很多。

更激进的“启动15% / 回撤3%”收益更高，总收益 `+154.0%`，最大回撤 `-22.7%`，但 `2023` 小幅亏损，且平均持仓占用升到 `33.0%`。它可能更接近“放大利润”的版本，但需要防止参数过拟合。

`120日位置10%-50%` 容量更大，成交 `798` 笔，平均持仓占用 `58.9%`，但最大回撤扩大到 `-29.6%`。如果后续目标是提高容量，可以研究它；如果目标是先找到更稳的正期望结构，应优先研究 `10%-35%`。

## 退出原因

以 `120日位置10%-35%，启动15% / 回撤3%` 为例：

| 退出原因 | 笔数 | 占比 | 平均净收益 |
| --- | ---: | ---: | ---: |
| 动态止盈 | 139 | 48.4% | +17.4% |
| 硬止损8% | 168 | 51.6% | -8.2% |

它的胜率并不高，核心是盈利单的平均幅度明显大于亏损单。这符合“低位回弹后，拿住少数真正走出来的票”的逻辑。

## 当前建议

不要再看原始 top10 全量，也不要扩大到 `10%-65%`。高位和中高位票会把回撤重新拉大。

下一步更科学的方向是固定仓位规则为“最多10只”，围绕 `120日位置10%-35%` 做失败样本研究：重点看 `2023` 和 `2024` 触发硬止损的票，在买入前和持有中有什么共同量价状态。目标不是继续调参数，而是解释为什么同样处在相对低位，有些票能趋势延伸，有些票只是弱反弹后继续下跌。
