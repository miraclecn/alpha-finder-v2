# up5in10 独立信号主规则 v1

## 规则状态

这份文档固化当前可继续研究的主规则。它不是最终实盘上线说明，而是后续接回、风控、容量研究的基准版本。

当前规则来自前序 `2022-2025` 调参研究，并用 `2020` 做了一次调参外验证。后续新增条件必须和本规则单独比较，不能再混入旧策略或其他袖套。

## 信号定义

- 研究对象：A 股日频、收盘后生成候选，下一交易日开盘执行。
- 信号来源：`up5in10` 路径分数独立信号。
- 日内排序：每日保留路径分数靠前的 `top10`。
- 过滤范围：只保留 `120日区间位置 >= 10% 且 < 35%`。
- 不采用高位票：`120日区间位置 >= 35%` 暂不进入主规则。
- `250日区间位置` 不替代 `120日区间位置`；最多作为风险观察或高位否决条件。

`120日区间位置` 的含义：

```text
(当日复权收盘价 - 过去120日最低价) / (过去120日最高价 - 过去120日最低价)
```

这个定义强调“相对低位但已经反弹一段”，不是买最低点。

## 执行规则

- 信号日收盘后选股，下一交易日开盘买入。
- 最多同时持有 `10` 只。
- 单只目标仓位为当前组合权益的 `15%`。
- 不使用杠杆，现金不足或仓位已满则跳过。
- A 股 `T+1`：买入当天不卖出。
- 成本：买入 `12bp`，卖出 `12bp`。
- 不设固定止盈。
- 不设最大持仓天数。
- 只在数据结束日做会计强制平仓；自然回测不在年末强制平仓。

## 卖出规则

### 硬止损

- 硬止损为 `6%`。
- 从买入后第一个可卖交易日起，如果日内最低价跌到买入价下方 `6%`，按 `买入价 * 0.94` 卖出。
- 加上双边交易成本后，硬止损交易的净亏损约为 `-6.23%`。

### 动态止盈

- 当持仓最高价相对买入价上涨达到 `15%` 后，动态止盈启动。
- 启动后，记录已形成高点。
- 后续如果日内最低价跌破 `已形成高点 * 0.97`，卖出。
- 为避免日内高低顺序不可知，移动止盈只使用“此前已经形成的高点”，不假设同一天先创新高再回落卖出。

例子：

```text
买入价 10.00 元
后续最高价达到 11.50 元，动态止盈启动
若之后跌到 11.50 * 0.97 = 11.155 元，触发动态止盈
```

## 为什么定为 6% 硬止损

在固定 `120日位置10%-35%`、单只 `15%`、最多 `10` 只、盈利 `15%` 启动、回撤 `3%` 的条件下，硬止损扫描结果显示：

| 硬止损 | 总收益 | 最大回撤 |
| --- | ---: | ---: |
| `5%` | `+170.98%` | `-22.08%` |
| `6%` | `+195.69%` | `-20.64%` |
| `8%` | `+194.79%` | `-29.87%` |
| `10%` | `+169.14%` | `-33.23%` |
| `12%` | `+166.93%` | `-37.54%` |

判断：`6%` 在收益和回撤之间更均衡。继续放宽止损主要放大回撤，没有明显提高期望。

## 120日与250日位置判断

最新对比使用同一套交易规则，只改变位置过滤。

| 过滤条件 | 2020调参外收益 / 回撤 | 2022-2025收益 / 回撤 |
| --- | ---: | ---: |
| `120日 10%-35%` | `+5.38% / -14.58%` | `+133.62% / -20.62%` |
| `250日 10%-35%` | `-6.46% / -15.28%` | `+69.87% / -26.36%` |
| `120日 10%-35% 且 250日 10%-35%` | `+1.21% / -10.25%` | `+55.26% / -21.72%` |
| `120日 10%-35% 且 250日 < 50%` | `+6.36% / -13.79%` | `+126.00% / -22.23%` |

判断：

- `250日 10%-35%` 不适合替代 `120日 10%-35%`。
- 强制要求 `250日 10%-35%` 会明显降低容量和收益。
- 如果后续要加长周期风控，更合理的是研究 `250日位置 < 50%` 这类高位否决，而不是把 `250日` 当主过滤。

## 动态止盈启动阈值判断

固定硬止损 `6%`、回撤 `3%`，只改变动态止盈启动阈值：

| 启动阈值 | 2020调参外收益 / 回撤 | 2022-2025收益 / 回撤 |
| --- | ---: | ---: |
| `15%` | `+5.38% / -14.58%` | `+133.62% / -20.62%` |
| `20%` | `+15.70% / -11.13%` | `+80.04% / -31.15%` |
| `25%` | `+18.93% / -11.09%` | `+53.47% / -36.91%` |
| `30%` | `+19.83% / -17.32%` | `+66.08% / -44.26%` |

判断：

- 提高启动阈值在 `2020` 这种强反弹年份有效。
- 但在 `2022-2025` 全样本明显恶化，尤其回撤扩大。
- 因此主规则暂不把启动阈值提高到 `20%` 或更高。

## 动态止盈回撤阈值判断

固定硬止损 `6%`、启动 `15%`，只改变启动后的回撤阈值：

| 回撤阈值 | 2020调参外收益 / 回撤 | 2022-2025收益 / 回撤 |
| --- | ---: | ---: |
| `2%` | `+6.80% / -13.77%` | `+129.76% / -18.81%` |
| `3%` | `+5.38% / -14.58%` | `+133.62% / -20.62%` |
| `5%` | `+0.73% / -15.75%` | `+97.07% / -23.29%` |
| `8%` | `-4.15% / -16.82%` | `+41.52% / -33.12%` |
| `10%` | `-4.92% / -18.63%` | `+32.02% / -33.33%` |

判断：

- `2%-3%` 是可接受区间。
- `3%` 作为主规则更稳妥；`2%` 更依赖成交和滑点质量。
- 放宽到 `5%` 以上不能解决卖飞问题，反而显著降低组合表现。

## 已知问题

### 容量不足

2020 调参外样本平均持仓只有 `0.87` 只，2022-2025 也只有 `2.70` 只。规则期望为正，但资金利用率不足。后续不能只看收益率，还要研究是否能在不降低质量的情况下提高有效信号数。

### 胜率低

主规则不是高胜率策略，而是依赖少数盈利交易覆盖大量小止损。2022-2025 胜率只有 `37.12%`，单笔中位数是硬止损附近的 `-6.23%`。

### 动态止盈会卖飞大牛股

在主规则下：

| 样本 | 总交易 | 动态止盈交易 | 120日内最高涨幅超过50%的交易 | 被动态止盈卖飞超过20个百分点 |
| --- | ---: | ---: | ---: | ---: |
| `2020` | `47` | `16` | `11` | `6` |
| `2022-2025` | `264` | `98` | `82` | `37` |

判断：卖飞是真问题，但不适合通过全局提高启动阈值或放宽回撤阈值解决。更合理的下一步是研究“动态止盈后接回”的条件。

### 接回研究最新状态

针对动态止盈后的接回，已经做了事件级、组合级和额外年份验证，结论是：

- `A` 条件，即“原始盈利至少 `20%` 且次日开盘不高于卖出价”有一定价值。
- `B` 条件，即“低价重破 3 日高点”不够稳，不进入主规则。
- `A` 在 `2020` 和 `2022-2025` 能增强组合，但在 `2021` 基本中性、在 `2026` 当前数据为负贡献。
- 因此接回暂不并入主规则，只保留为后续观察模块。

详细见：[2026-05-13-up5in10-dynamic-reentry-study.md](/home/nan/alpha-find-v2/docs/research/2026-05-13-up5in10-dynamic-reentry-study.md)

## 后续研究优先级

1. 接回条件继续细化：只保留 `A`，研究能否进一步压缩到更稳定的子环境。
2. 失败票过滤：研究触发 `6%` 硬止损前后的量价状态，减少无效反弹。
3. 长周期高位否决：验证 `250日位置 < 50%` 是否能稳定降低风险，而不是只在少数年份有效。
4. 容量提升：在 `120日10%-35%` 附近寻找更多可交易信号，而不是盲目扩大到 `10%-50%`。
