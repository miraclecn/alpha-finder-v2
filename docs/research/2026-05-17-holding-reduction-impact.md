# 2023-2025 持仓数下调影响研究

## 结论

- 把持仓数从 `16-20` 往下压，**不是线性变好**。
- 对当前最强的 `revenue_growth + dividend_yield` 来说：
  - `16-20` 是明显更优的平台
  - 压到 `12-14` 以后，主动收益和最差年份主动收益都会明显变差
- 对保留技术类约束的 `sector_relative_valuation + revenue_growth + volume_overheat_control` 来说：
  - `16` 已经接近可接受下限
  - 再往下压到 `14` 或 `12`，`2024` 会重新转负

## 研究对象

只研究上一轮最有代表性的两条主线：

1. 高收益主线：
   - `revenue_growth + dividend_yield`
2. 保留技术约束主线：
   - `sector_relative_valuation + revenue_growth + volume_overheat_control`

- `biweekly`

## 实用建议

- 如果你要的是**更少持仓，但尽量不明显伤收益**：
  - `growth + dividend` 这条线上，`16` 是很好的压缩点
  - 从 `20 -> 16`：
    - `active ann.` 只从 `+13.55%` 降到 `+13.38%`
    - `min-year active` 反而从 `+11.91%` 升到 `+12.24%`
    - `MDD` 从 `-16.04%` 改善到 `-15.95%`
- 如果你还想继续压到 `12`：
  - 收益仍然不差
  - 但稳定性会明显变弱，不是当前首选
- 如果你想压到 `10`：
  - 只在 `monthly growth + dividend` 下还能勉强保住三年都正主动收益
  - 但 `min-year active` 只剩 `+0.57%`，缓冲太薄
- `8` 和 `6` 不建议继续考虑。
- 如果你坚持保留技术类约束：
  - 不建议低于 `16`
  - 更合理的是 `16-18`
