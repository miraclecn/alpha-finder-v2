# 2022-2025 A 股 10 日内先涨 5% 样本：启动前 30 日量价关系研究

## 对象

- 样本区间：`2022-01-01` 到 `2025-12-31`
- 市场范围：A 股，剔除 `beijing`
- 候选日要求：当日 `not ST`、`not suspended`
- 成功事件定义：从候选日 `t0` 起，未来 `10` 个交易日内 `high_adj >= close_adj[t0] * 1.05`
- 回看窗口：`t-30` 到 `t-1`
- 成交量基线：前 `20` 日成交额中位数
- 量价状态定义沿用仓库已有口径：
  - `expand_up`
  - `expand_down`
  - `expand_flat`
  - `contract_up`
  - `contract_down`
  - `contract_flat`
  - `neutral`

产物：

## 逐日量价关系：不是某一天突然爆量，而是 30 天内逐步强化

为了看清楚节奏，把 `t-30` 到 `t-1` 分成三段：

- `setup`：`t-30` 到 `t-21`
- `mid`：`t-20` 到 `t-11`
- `launch_pad`：`t-10` 到 `t-1`

这里的数值都是“成功样本减去全部候选样本”的差值。

| 阶段 | 日收益差 | 量比差 | 收益-量比相关差 | 放量上涨占比差 | 放量下跌占比差 | 缩量横盘占比差 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `setup` | `+0.0077%` | `+0.0162` | `+0.0047` | `+0.50pct` | `+0.17pct` | `-0.72pct` |
| `mid` | `+0.0177%` | `+0.0456` | `+0.0042` | `+1.10pct` | `+0.54pct` | `-1.43pct` |
| `launch_pad` | `+0.0329%` | `+0.0579` | `+0.0016` | `+1.42pct` | `+0.75pct` | `-1.88pct` |

这张表比“平均涨跌幅”更重要，因为它说明了三件事：

1. 成功样本不是先靠收益领先，而是先靠量价耦合强化。
2. 越靠近启动点，成交量差异越大，`t-10` 到 `t-1` 明显强于 `t-30` 到 `t-21`。
3. 成功样本最稳定的共性不是“只会放量上涨”，而是“缩量横住的时间更少，方向性交易更多”。

也就是说，真正有机会在 `10` 日内先冲出 `5%` 的票，在启动前 `30` 天更像是在从“无效安静”切换到“有效活跃”。

这意味着实盘里不要把“临门一脚前有带量回撤”机械理解为坏事。对这类 `10` 日内能冲 `5%` 的票，最后几天更常见的是：

- 只要价格动，量就更容易跟
- 横盘缩量减少
- 方向切换速度更快

## 收益和成交量的耦合，往往先于最后一波量能放大

收益-量比相关性差值最大的相对日不在最后 5 天，而是在：

- `t-23`
- `t-22`
- `t-21`
- `t-20`
- `t-19`

对应的相关性差值大约在 `+0.008` 到 `+0.014`。

这说明成功样本的一个更早期特征是：

- 价格一旦上涨，成交量更愿意跟
- 价格一旦转弱，量也更容易放出来

换句话说，临近启动前的大量差异只是结果，更早一点出现的是“价动量随”的结构性强化。

## 每天之间的量价关系：成功样本更容易从方向状态继续向前推进

把相邻两天状态转移汇总后，成功样本相对基线最强的正向转移是：

| 前一日 -> 后一日 | 基线转移率 | 成功样本转移率 | 差值 |
| --- | ---: | ---: | ---: |
| `expand_up -> expand_up` | `28.92%` | `30.85%` | `+1.94pct` |
| `expand_flat -> expand_up` | `24.11%` | `25.98%` | `+1.88pct` |
| `contract_flat -> contract_down` | `18.27%` | `19.99%` | `+1.73pct` |
| `contract_down -> contract_down` | `22.19%` | `23.69%` | `+1.50pct` |
| `expand_down -> expand_up` | `23.42%` | `24.73%` | `+1.30pct` |
| `expand_flat -> expand_down` | `18.34%` | `19.46%` | `+1.13pct` |

最强的负向转移是：

| 前一日 -> 后一日 | 基线转移率 | 成功样本转移率 | 差值 |
| --- | ---: | ---: | ---: |
| `contract_flat -> contract_flat` | `32.52%` | `30.25%` | `-2.27pct` |
| `contract_down -> contract_flat` | `31.76%` | `29.93%` | `-1.83pct` |
| `contract_up -> contract_flat` | `28.70%` | `27.10%` | `-1.60pct` |
| `expand_flat -> expand_flat` | `18.66%` | `17.16%` | `-1.50pct` |
| `expand_up -> neutral` | `26.80%` | `25.44%` | `-1.37pct` |
| `expand_flat -> neutral` | `35.41%` | `34.05%` | `-1.36pct` |

这些转移关系说明：

1. 成功样本更容易把“带量状态”延续下去，不容易重新掉回 `neutral` 或 `contract_flat`。
2. `expand_up -> expand_up` 明显更常见，说明真正有希望在 `10` 日内继续冲高的票，往往不是孤立的一根放量阳线，而是至少会多给一两次带量延续。
3. `expand_down -> expand_up` 也更常见，说明启动前带量洗盘、带量反包是常见路径。
4. 纯粹的“缩量横着耗时间”在成功样本里更少见，这和前面逐日画像是完全一致的。

## 序列模式：哪些状态组合更像要在 10 天内冲出 5%

候选级别的序列模式里，成功样本最强的正差值是：

| 模式 | 基线出现率 | 成功样本出现率 | 差值 |
| --- | ---: | ---: | ---: |
| `expand_up` 连续 2 天 | `53.73%` | `57.64%` | `+3.91pct` |
| `expand_up` 连续 3 天 | `20.95%` | `24.39%` | `+3.45pct` |
| `expand_down -> expand_up` | `39.17%` | `42.58%` | `+3.41pct` |
| 任意 2 天缩量后接 `expand_up` | `26.31%` | `27.22%` | `+0.91pct` |
| `contract_down -> expand_up` | `11.59%` | `12.70%` | `+1.11pct` |

相反，成功样本里反而更少见的是：

| 模式 | 差值 |
| --- | ---: |
| `contract_flat` 连续 2 天后接 `expand_up` | `-0.60pct` |
| `contract_flat` 连续 3 天后接 `expand_up` | `-0.42pct` |
| `expand_up` 之后再接两天缩量 | `-0.07pct` |
| `expand_up` 之后再接两天缩量横盘 | `-0.22pct` |

这个结果很重要，因为它修正了很多直觉：

1. `持续缩量后放量` 不是不能用，但更有效的是“缩量状态里带一些方向漂移”，不是纯 `contract_flat` 死横。
2. `放量上涨后持续缩量` 并不是这类样本最典型的好结构，它比基线还略弱。
3. 更像成功样本的路径是：
   - 带量上攻后再带量延续
   - 带量下杀后快速反包
   - 缩量回撤或缩量下行后接放量上攻

## 主板交叉验证

主板结果和全市场方向一致，但强度更大：

- `launch_pad` 阶段量比差扩大到 `+0.0639`
- `t-1` 量比差扩大到 `+0.0711`
- `expand_up` 连续 2 天差值扩大到 `+4.50pct`
- `expand_up` 连续 3 天差值扩大到 `+3.80pct`
- `expand_down -> expand_up` 差值扩大到 `+3.83pct`

这说明如果把样本收敛到主板，最后 `10` 天内的“活跃换手 + 方向延续”特征会更清楚。

## 结论

对“未来 `10` 个交易日内先涨 `5%`”这类样本，启动前 `30` 天最普适的量价规律不是一句“放量上涨”就能概括，真实更像下面这组组合：

1. `t-30` 到 `t-20`：先出现量价耦合强化，价格一动，量更愿意跟。
2. `t-20` 到 `t-10`：成交量差持续扩大，放量上涨和放量下跌同时变多，纯缩量横盘明显减少。
3. `t-10` 到 `t-1`：量差达到峰值，最强窗口集中在 `t-8` 到 `t-1`。
4. 日与日之间：成功样本更容易从方向状态继续推进，不容易退回 `neutral` 或 `contract_flat`。
5. 序列上：`expand_up` 连续出现、`expand_down -> expand_up`、`contract_down -> expand_up` 更像有效前奏；纯 `contract_flat` 死横后再启动并不是最强模式。

如果把这些规律翻译成更实盘的观察语言，就是：

- 不要只盯一根大阳线，要看最后 `8-10` 天是否进入持续活跃换手。
- 不要把临近启动前的所有带量回撤都当坏事，关键看它后面是否能迅速回到 `expand_up`。
- 真正该警惕的不是短期带量回踩，而是反复回到 `contract_flat`、`neutral`，说明量价关系又松掉了。
