# 当前最强策略的 2021 / 2022 / 2026 YTD Alpha 稳定性检查

## 检查对象

使用当前收益最强、且在 `2023-2025` 三年都为正主动收益的组合：

- `biweekly`
- `20` 只持仓
- `revenue_growth + dividend_yield`

回测约束与前面一致：

- `PortfolioBacktester`
- `next_day_open`
- `T+1`
- 停牌 / 开盘涨跌停锁 / lot size / participation cap
- `base_a_share_cash`

## 时间边界

- `2021`: `2021-01-04` 到 `2021-12-31`
- `2022`: `2022-01-04` 到 `2022-12-30`
- `2026 YTD`: `2026-01-05` 到 `2026-04-28`

说明：

- 行情数据本身到 `2026-05-15`
- 但当前 benchmark 状态文件只覆盖到 `2026-04-28`
- 所以 `2026` 这次只能严格评估到 `2026-04-28`

## 判断

结论很直接：

- `2021` 有正 alpha，但很弱
- `2022` 有正 alpha，而且是在熊市里相对 benchmark 更抗跌
- `2026 YTD` 已经是负 alpha

因此，这个“当前最强策略”：

- **不能算在 `2021`、`2022`、`2023`、`2024`、`2025`、`2026 YTD` 上稳定获取 alpha**

更准确的说法是：

- 它在 `2022-2025` 这段更有竞争力
- `2021` 边际优势很薄
- `2026 YTD` 截至 `2026-04-28` 已经失效

## 含义

这说明当前最强策略虽然把 `2023-2025` 做得很好，但仍然带有明显环境依赖：

- 并不是“跨年份普适 alpha”
- 更像是对某类增长 / 分红风格阶段有较强暴露

如果要继续推进，下一步不该再默认它已经“稳定”，而应该转成：

1. 拆解 `2026 YTD` 失败来源
2. 看是不是行业或风格集中导致
3. 再决定是否需要 overlay、行业约束、或 descriptor 权重重构
