# 10 日内先涨 5% 路径分数：日频筛选阈值研究

## 对象

承接前一份路径分数验证：

- [2026-05-12-up5in10-path-score-validation.md](./2026-05-12-up5in10-path-score-validation.md)

路径分数定义：

`Score = z(mean_turnover10) - z(contract_flat_rate10) + z(expand_up_persist) + 0.5 * z(down_to_up)`

研究目的不是再证明它有没有排序能力，而是回答更实盘的问题：

- 如果把这个分数当成日频筛选器，阈值切在哪更合适？
- 是要 `p70` 这种宽口径，还是 `p90` / `p95` 这种极窄口径？

这次固定：

- 训练年份：`2022-2025`

- `2026` 数据截止数据库现有最新交易日：`2026-04-28`
- 阈值使用训练集分位数：`p50 / p60 / p70 / p80 / p90 / p95`

## 先说结论

如果只是为了把这个分数变成“日频候选筛选器”，最均衡的阈值是：

- 全市场：`p80`
- 主板：`p80`

如果你愿意明显牺牲覆盖率来换更高的命中率，可以用：

- 全市场：`p90`
- 主板：`p90`

`p95` 也有效，但更像“极窄聚焦模式”，不太像常规日频筛选的主阈值。

## 为什么 `p80` 最均衡

先看全市场留一年样本外平均结果：

| 阈值 | 平均覆盖率 | 平均成功率 | 相对基准提升 |
| --- | ---: | ---: | ---: |
| `p50` | `49.92%` | `53.12%` | `+4.32pct` |
| `p60` | `39.89%` | `54.36%` | `+5.56pct` |
| `p70` | `29.90%` | `55.78%` | `+6.98pct` |
| `p80` | `20.06%` | `57.61%` | `+8.81pct` |
| `p90` | `10.25%` | `59.66%` | `+10.86pct` |
| `p95` | `5.31%` | `61.02%` | `+12.22pct` |

这里最关键的不是“哪个成功率最高”，而是边际交换：

1. `p70 -> p80`
   覆盖率从 `29.9%` 降到 `20.1%`
   成功率从 `55.8%` 升到 `57.6%`
   这笔交换还是划算的。

2. `p80 -> p90`
   覆盖率直接再砍半，从 `20.1%` 降到 `10.3%`
   但成功率只多 `2.05pct`
   收益有，但开始变得不便宜。

3. `p90 -> p95`
   覆盖率再砍半，从 `10.3%` 降到 `5.3%`
   成功率只再多 `1.37pct`
   这更像高浓度过滤，而不是通用筛选器。

所以 `p80` 是一个很自然的拐点：

- 还保留了约 `20%` 的候选覆盖率
- 同时把成功率拉到接近 `58%`
- 相比基准成功率平均多出 `8.8pct`

这更像“均衡日频阈值”。

## 主板结果更干净，但结论没变

主板留一年样本外平均结果：

| 阈值 | 平均覆盖率 | 平均成功率 | 相对基准提升 |
| --- | ---: | ---: | ---: |
| `p50` | `50.00%` | `50.23%` | `+4.36pct` |
| `p60` | `39.89%` | `51.54%` | `+5.67pct` |
| `p70` | `30.00%` | `53.06%` | `+7.19pct` |
| `p80` | `20.15%` | `55.09%` | `+9.22pct` |
| `p90` | `10.33%` | `57.60%` | `+11.73pct` |
| `p95` | `5.34%` | `59.04%` | `+13.16pct` |

主板上梯度更强，但形状没变：

- `p80` 仍是最自然的平衡点
- `p90` 适合更激进、更少票的模式
- `p95` 太窄，更适合高确信度二次筛选，而不是第一层通用阈值

## 如果把阈值翻译成实盘语言

### `p70`

适合：

- 想保留较宽候选池
- 后面还有别的强过滤器
- 想把路径分数当成“前置提纯”而不是最终买点

特点：

- 覆盖率还在 `30%` 左右
- 成功率提升稳定，但不算特别强

### `p80`

适合：

- 把路径分数当成第一层主要筛选器
- 希望覆盖率和成功率都不过分极端

特点：

- 覆盖率大约 `20%`
- 样本外平均成功率提升接近 `+9pct`
- 是最像“主阈值”的位置

### `p90`

适合：

- 候选数已经很多，想进一步压缩
- 更重视命中率，而不是样本覆盖

特点：

- 覆盖率约 `10%`
- 成功率还能继续明显抬升
- 但相对 `p80` 已经开始进入“用覆盖率换命中率”的后半段

### `p95`

适合：

- 做二次聚焦
- 或只想研究最强路径结构

不太适合：

- 直接当通用日频阈值

原因：

- 覆盖率只有 `5%` 左右
- 成功率提升还在继续，但边际收益已经明显递减

## 科学上更合理的阈值建议

如果目标是“实盘规则期望为正，且不能太低”，只看这一个路径分数时，更合理的用法不是追求最高成功率，而是选一个结构稳定、覆盖率不至于太稀的点。

所以建议分两档：

### 主阈值

- `p80`

理由：

- 全市场和主板都稳定
- 留一年验证与 `2021/2026` 外样本都稳定
- 覆盖率约 `20%`
- 成功率提升已经够明显

### 强确认阈值

- `p90`

理由：

- 当你还叠加了别的结构信号，或者只想要高确信度候选时更合适
- 但不建议单独把它当成唯一默认阈值

## 当前最务实的落地方式

如果下一步要接到现有日频研究或选股器里，我建议直接这样用：

1. 先对每天全部候选股算这个路径分数
2. 第一层筛选先切 `p80`
3. 如果当天候选数仍太多，再叠加别的条件或切到 `p90`
4. 不建议一开始就默认 `p95`

原因很简单：

- `p80` 更像一个可持续使用的筛选器
- `p90/p95` 更像浓缩器

两者角色不同，不要混用

## 结论

这次的路径分数已经可以当成一个真正的日频筛选器来用。

它最合适的阈值不是“越高越好”，而是：

- 默认主阈值：`p80`
- 高确信度阈值：`p90`

如果后面还要继续推进，最值得做的不是再微调这几个百分位，而是直接把：

- `p80`
- `p90`

分别接到你现有的候选池上，看最终组合收益、回撤和换手怎么变。
